# Shoot checklist — read this on the phone

One screen. Full reasoning is in
`pale-background-fixture-shoot.md`; you do not need it while shooting.

**Target: 16–24 spreads. Tick as you go.**

---

## Every shot, same three rules

- **Manual capture.** Not the auto toggle.
- **One frame per spread.** No multi-zoom.
- **Don't compose for the app.** Hold it as you
  normally would, even if the framing looks bad.

---

## POSITIVES — room visible all round the book

Aim 8–12. Two per surface beats ten on one.

- [ ] [ ] pale sofa (the known-hard one)
- [ ] [ ] wooden desk or table
- [ ] [ ] **white / near-white** surface ← never shot,
        the nastiest case
- [ ] [ ] patterned: tablecloth, rug, bedspread
- [ ] [ ] dark surface (control — the easy case)
- [ ] [ ] on your lap, clutter behind

## NEGATIVES — the spread FILLS the frame

Aim 6–8. Deliberately cut the book off.

- [ ] [ ] [ ] [ ] handheld, running off **all four** edges
- [ ] [ ] handheld, off **one or two** edges only
- [ ] [ ] flat on a desk, tight, phone overhead

These are half the value. Don't skip them
because they look like mistakes — they are the
case the program has never seen.

---

## Spread across the set — don't hold constant

- **3+ different books.** Different paper colour,
  page size, binding. One with **coloured page
  edges or tabs** is especially wanted.
- **Light:** daylight / room light at night /
  one with visible glare or a shadow across it.
- **Content:** 2+ spreads that are mostly
  **picture**, and 1 nearly **blank**.

---

## Note per shot — one line is plenty

```
surface | book | light | pos or neg
sofa    | red  | day   | pos
```

Anything works: notes app, voice memo, paper.
Written on the spot saves an hour of guessing
later. If you note nothing else, note **pos/neg**.
